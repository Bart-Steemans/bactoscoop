SignalCorrelation¶

class bactoscoop.signalcorrelation.SignalCorrelation(df, channel1, channel2, feature, method_name, prepared_feature=None)¶

Select an implemented relationship between two channel-prefixed feature columns.

The feature must exist for both channels. calculate mutates the supplied DataFrame; prepared_feature can cache the numerical input arrays.

Parameters:

  • df – DataFrame to inspect, transform, or augment. Correlation mutates it in place and returns it.

  • channel1 – First channel prefix for the matching feature.

  • channel2 – Second channel prefix for the matching feature.

  • feature – Unprefixed shared feature name; corresponding channel-prefixed columns must exist.

  • method_name – Implemented correlation selector, such as pearson, manders, or ratio.

  • prepared_feature – Optional cached signal arrays and validity mask for a channel/feature pair.

Returns:

None (no explicit return statement).

Assigned state: self.df, self.channel1, self.channel2, self.feature, self.method_name, self.prepared_feature, self.method.
