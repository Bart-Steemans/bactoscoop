SignalCorrelation
~~~~~~~~~~~~~~~~~

.. py:class:: SignalCorrelation(df, channel1, channel2, feature, method_name, prepared_feature=None)

   Compare the same feature between two channels for each cell.

   The feature must exist for both channels. calculate adds a measurement column to the supplied DataFrame and returns that same table. Invalid input pairs or undefined measurements yield NaN; prepared_feature optionally caches the input arrays.

   :param df: DataFrame to inspect, transform, or augment. Correlation mutates it in place and returns it.
   :param channel1: First channel prefix for the matching feature.
   :param channel2: Second channel prefix for the matching feature.
   :param feature: Unprefixed shared feature name; corresponding channel-prefixed columns must exist.
   :param method_name: Implemented correlation selector, such as pearson, manders, or ratio.
   :param prepared_feature: Optional cached signal arrays and validity mask for a channel/feature pair.

   :returns: None (no explicit return statement).

   **Assigned state:** ``self.df``, ``self.channel1``, ``self.channel2``, ``self.feature``, ``self.method_name``, ``self.prepared_feature``, ``self.method``.
