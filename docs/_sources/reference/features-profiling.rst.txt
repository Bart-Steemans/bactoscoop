Profiling features
==================

**Prerequisites:** Loaded matching fluorescence channel and valid cell geometry; channel background subtraction is performed.

A failed cell calculation omits that family row and records the failure.
Missing values in a merged table are not automatically zero. Numerical NaN can
also arise within a returned measurement. The object retention option explicitly
sets invalid mesh-dependent aggregates to NaN.

axial_intensity
---------------

**Exported column:** ``<channel>_axial_intensity``

**Meaning:** Axial intensity profile along the cell.

Calculation: Sample intensity along the cell midline with perpendicular averaging and apply Gaussian smoothing.
Explanation: This is the 1D signal profile along the long axis of the cell.

**Units:** Image intensity units after the family-specific preprocessing. **Value shape:** Array/list per cell (per object for detailed object outputs).

**Availability:** emitted whenever this family calculation succeeds; ``all_data`` does not gate this key.

**Normalization:** No additional export-level normalization; the calculation below determines family-specific preprocessing.

**Current assignment expression** (a tuple expression can produce several named outputs):

.. code-block:: python

   u.measure_smoothened_intensity(cropped_ml, cropped_signal_interp2d, width=10)

**Calculation helpers:** :py:func:`bactoscoop.utilities.measure_smoothened_intensity`.

normalized_axial_intensity
--------------------------

**Exported column:** ``<channel>_normalized_axial_intensity``

**Meaning:** Min-max normalized axial intensity profile.

Calculation: Apply per-cell min-max normalization: (x - min) / (max - min).
Explanation: This rescales the profile to the 0-1 range so cells can be compared independent of absolute intensity differences.

**Units:** Dimensionless (GLCM descriptors use quantized intensity bins). **Value shape:** Array/list per cell (per object for detailed object outputs).

**Availability:** emitted whenever this family calculation succeeds; ``all_data`` does not gate this key.

**Normalization:** Within-cell min–max scaling for normalized axial/mesh/contour profiles; complemented contour intensity is transformed separately in the helper.

**Current assignment expression** (a tuple expression can produce several named outputs):

.. code-block:: python

   u.normalize_per_cell(cell.profiling_features['axial_intensity'])

**Calculation helpers:** :py:func:`bactoscoop.utilities.normalize_per_cell`.

-------------------------------

**Exported column:** ``<channel>_signal_constriction_degree_mesh``

**Meaning:** Signal constriction degree from the mesh-intensity profile.

Calculation: Interpolate the relevant profile, identify the strongest local minimum in the central part of the profile, and report either the relative depth of that minimum or its normalized position along the cell.
Explanation: These features measure whether there is a narrowing or dip in the signal and where that constriction occurs.

cell_glcm_dissimilarity
-----------------------

**Exported column:** ``<channel>_cell_glcm_dissimilarity``

**Meaning:** Cell texture dissimilarity (GLCM).

Calculation: Build the gray-level co-occurrence matrix (GLCM) for the relevant image representation and compute sum(P(i,j) \* \|i-j\|) across gray-level pairs, averaged over the angles used by bactoscoop.
Explanation: Dissimilarity increases when neighboring pixels tend to have different intensities and is lower when neighboring pixels are more alike.

**Units:** Dimensionless (GLCM descriptors use quantized intensity bins). **Value shape:** Scalar.

**Availability:** emitted whenever this family calculation succeeds; ``all_data`` does not gate this key.

**Normalization:** No additional export-level normalization; the calculation below determines family-specific preprocessing.

cell_glcm_correlation
---------------------

**Exported column:** ``<channel>_cell_glcm_correlation``

**Meaning:** Cell texture correlation (GLCM).

Calculation: Build the gray-level co-occurrence matrix (GLCM) for the relevant image representation and compute the Haralick correlation term, which measures the covariance of paired gray levels after normalization by their standard deviations.
Explanation: Correlation is high when neighboring pixel intensities vary together in a predictable linear way and lower when that relationship is weak.

**Units:** Dimensionless (GLCM descriptors use quantized intensity bins). **Value shape:** Scalar.

cell_glcm_homogeneity
---------------------

**Exported column:** ``<channel>_cell_glcm_homogeneity``

**Meaning:** Cell texture homogeneity (GLCM).

Calculation: Build the gray-level co-occurrence matrix (GLCM) for the relevant image representation and compute sum(P(i,j) / (1 + (i-j)^2)) across gray-level pairs, averaged over angles.
Explanation: Homogeneity is high when most co-occurrences lie near the diagonal of the GLCM, meaning neighboring pixels usually have similar intensities.
