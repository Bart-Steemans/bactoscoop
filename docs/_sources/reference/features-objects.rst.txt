Objects features
================

**Prerequisites:** Detected contours for the channel; valid object meshes for mesh-dependent quantities.

A failed cell calculation omits that family row and records the failure.
Missing values in a merged table are not automatically zero. Numerical NaN can
also arise within a returned measurement. The object retention option explicitly
sets invalid mesh-dependent aggregates to NaN.

cell_total_obj_rect_length
--------------------------

**Exported column:** ``<channel>_cell_total_obj_rect_length``

**Meaning:** Total object rectangle length per cell.

Calculation: Fit a minimum-area rectangle to each object contour with cv2.minAreaRect, then report either the summed major-axis lengths or the mean minor-axis widths.
Explanation: These features describe object size in a simple rectangle-based way.

**Units:** µm. **Value shape:** Scalar.

**Availability:** emitted whenever this family calculation succeeds; ``all_data`` does not gate this key.

**Normalization:** No additional export-level normalization; the calculation below determines family-specific preprocessing.

**Current assignment expression** (a tuple expression can produce several named outputs):

.. code-block:: python

   u.get_object_rect_length(object_contours, px)

**Calculation helpers:** :py:func:`bactoscoop.utilities.get_object_rect_length`.

cell_obj_contour_avg_bending_energy
-----------------------------------

**Exported column:** ``<channel>_cell_obj_contour_avg_bending_energy``

**Meaning:** Mean object contour bending energy per cell.

Calculation: sum(curvature^2) / line\_length for the corresponding contour or midline.
Explanation: Bending energy summarizes how much the shape bends overall; larger values indicate a more strongly curved line.
The current helper sums sampled curvature squared and divides by physical line length. This is sampling-dependent and is not an arc-length integral.

**Units:** µm⁻³ under the implemented sum(curvature²)/length. **Value shape:** Scalar.

**Availability:** emitted whenever this family calculation succeeds; ``all_data`` does not gate this key.

glcm_obj_homogeneity
--------------------

**Exported column:** ``<channel>_glcm_obj_homogeneity``

**Meaning:** Object texture homogeneity (GLCM).

Calculation: Build the gray-level co-occurrence matrix (GLCM) for the combined object-mask image and compute sum(P(i,j) / (1 + (i-j)^2)) across gray-level pairs, averaged over angles.
