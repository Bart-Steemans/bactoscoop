Membrane features
=================

**Prerequisites:** Loaded channel, valid cell geometry, and detected object contours for that channel; measurements sample the reconstructed cell contour.

A failed cell calculation omits that family row and records the failure.
Missing values in a merged table are not automatically zero. Numerical NaN can
also arise within a returned measurement. The object retention option explicitly
sets invalid mesh-dependent aggregates to NaN.

cell_perimeter
--------------

**Exported column:** ``<channel>_cell_perimeter``

**Meaning:** Cell contour perimeter.

Calculation: Sum the distances between consecutive points of the subpixel contour.
Explanation: This is the total contour length around the cell boundary in 2D.

**Units:** µm. **Value shape:** Scalar.

**Availability:** emitted whenever this family calculation succeeds; ``all_data`` does not gate this key.

**Normalization:** No additional export-level normalization; the calculation below determines family-specific preprocessing.

**Current assignment expression** (a tuple expression can produce several named outputs):

.. code-block:: python

   u.get_cell_perimeter_measurements(cropped_contour, area, px)

**Calculation helpers:** :py:func:`bactoscoop.utilities.get_cell_perimeter_measurements`.

normalized_contour_intensity
----------------------------

**Exported column:** ``<channel>_normalized_contour_intensity``

**Meaning:** Normalized membrane contour intensity profile.

Calculation: Apply per-cell min-max normalization: (x - min) / (max - min).
Explanation: This rescales the profile to the 0-1 range so cells can be compared independent of absolute intensity differences.

**Units:** Dimensionless (GLCM descriptors use quantized intensity bins). **Value shape:** Array/list per cell (per object for detailed object outputs).

**Availability:** emitted whenever this family calculation succeeds; ``all_data`` does not gate this key.

**Normalization:** Within-cell min–max scaling for normalized axial/mesh/contour profiles; complemented contour intensity is transformed separately in the helper.

**Current assignment expression** (a tuple expression can produce several named outputs):

.. code-block:: python

   u.normalize_per_cell(cell.membrane_features['contour_intensity'])

**Calculation helpers:** :py:func:`bactoscoop.utilities.normalize_per_cell`.

complemented_contour_intensity
------------------------------

**Exported column:** ``<channel>_complemented_contour_intensity``

**Meaning:** Complemented membrane contour intensity profile.

Calculation: Split the normalized contour profile into two halves, reverse one half, and average opposite positions together.
Explanation: This folds the two sides of the membrane onto one common coordinate system for easier comparison.

**Units:** Image intensity units after the family-specific preprocessing. **Value shape:** Array/list per cell (per object for detailed object outputs).

**Availability:** emitted whenever this family calculation succeeds; ``all_data`` does not gate this key.

**Normalization:** Within-cell min–max scaling for normalized axial/mesh/contour profiles; complemented contour intensity is transformed separately in the helper.

glcm_contour_dissimilarity
--------------------------

**Exported column:** ``<channel>_glcm_contour_dissimilarity``

**Meaning:** Membrane texture dissimilarity (GLCM).

Calculation: Build the gray-level co-occurrence matrix (GLCM) for the contour-intensity profile and compute sum(P(i,j) \* \|i-j\|) across gray-level pairs, averaged over the angles used by bactoscoop.
Explanation: Dissimilarity increases when neighboring pixels tend to have different intensities and is lower when neighboring pixels are more alike.

**Units:** Dimensionless (GLCM descriptors use quantized intensity bins). **Value shape:** Scalar.

**Availability:** emitted whenever this family calculation succeeds; ``all_data`` does not gate this key.

**Normalization:** No additional export-level normalization; the calculation below determines family-specific preprocessing.

**Current assignment expression** (a tuple expression can produce several named outputs):

glcm_contour_correlation
------------------------

**Exported column:** ``<channel>_glcm_contour_correlation``

**Meaning:** Membrane texture correlation (GLCM).

Calculation: Build the gray-level co-occurrence matrix (GLCM) for the contour-intensity profile and compute the Haralick correlation term, which measures the covariance of paired gray levels after normalization by their standard deviations.
Explanation: Correlation is high when neighboring pixel intensities vary together in a predictable linear way and lower when that relationship is weak.

**Units:** Dimensionless (GLCM descriptors use quantized intensity bins). **Value shape:** Scalar.

**Availability:** emitted whenever this family calculation succeeds; ``all_data`` does not gate this key.

**Normalization:** No additional export-level normalization; the calculation below determines family-specific preprocessing.

glcm_contour_homogeneity
------------------------

**Exported column:** ``<channel>_glcm_contour_homogeneity``

**Meaning:** Membrane texture homogeneity (GLCM).

Calculation: Build the gray-level co-occurrence matrix (GLCM) for the contour-intensity profile and compute sum(P(i,j) / (1 + (i-j)^2)) across gray-level pairs, averaged over angles.
Explanation: Homogeneity is high when most co-occurrences lie near the diagonal of the GLCM, meaning neighboring pixels usually have similar intensities.

**Units:** Dimensionless (GLCM descriptors use quantized intensity bins). **Value shape:** Scalar.
