Morphological features
======================

**Prerequisites:** Cell contour, mesh, midline, phase image, and physical calibration.

A failed cell calculation omits that family row and records the failure.
Missing values in a merged table are not automatically zero. Numerical NaN can
also arise within a returned measurement. The object retention option explicitly
sets invalid mesh-dependent aggregates to NaN.

cell_length
-----------

**Exported column:** ``cell_length``

**Meaning:** Cell length along the mesh midline.

Calculation: Sum the step lengths between successive mesh midpoints along the cell axis.
Explanation: This is the measured pole-to-pole length of the cell, following the fitted midline rather than a simple straight line.

**Units:** µm. **Value shape:** Scalar.

**Availability:** emitted whenever this family calculation succeeds; ``all_data`` does not gate this key.

**Normalization:** No additional export-level normalization; the calculation below determines family-specific preprocessing.

**Current assignment expression** (a tuple expression can produce several named outputs):

.. code-block:: python

   u.get_length(step_length)

**Calculation helpers:** :py:func:`bactoscoop.utilities.get_length`.

`Source assignment, line 85 <../source-code/features.html#features-85>`_; :py:meth:`bactoscoop.features.Features.morphological`.

cell_width
----------

**Exported column:** ``cell_width``

**Meaning:** Cell body width.

Calculation: Compute the width of every mesh segment as the distance between (x1, y1) and (x2, y2), sort those widths, and take the mean of the widest one-third.
Explanation: This gives a robust estimate of the cell body width while reducing the influence of the narrow poles.

**Units:** µm. **Value shape:** Scalar.

**Availability:** emitted whenever this family calculation succeeds; ``all_data`` does not gate this key.

**Normalization:** No additional export-level normalization; the calculation below determines family-specific preprocessing.

**Current assignment expression** (a tuple expression can produce several named outputs):

.. code-block:: python

   u.get_avg_width(cell.x1, cell.y1, cell.x2, cell.y2, px)

**Calculation helpers:** :py:func:`bactoscoop.utilities.get_avg_width`.

`Source assignment, line 86 <../source-code/features.html#features-86>`_; :py:meth:`bactoscoop.features.Features.morphological`.

cell_volume
-----------

**Exported column:** ``cell_volume``

**Meaning:** Cell estimated volume.

Calculation: Treat each mesh segment as a cylinder with radius width/2, integrate pi\*(width/2)^2 along the cell length using the trapezoidal rule, and sum the segments.
Explanation: This estimates the 3D volume of the bacterium from its 2D mesh.

**Units:** µm³. **Value shape:** Scalar.

**Availability:** emitted whenever this family calculation succeeds; ``all_data`` does not gate this key.

**Normalization:** No additional export-level normalization; the calculation below determines family-specific preprocessing.

cell_sphericity
---------------

**Exported column:** ``cell_sphericity``

**Meaning:** Cell sphericity descriptor.

Calculation: (1.5\*pi\*(cell\_perimeter/(2\*pi))^1.5) / cell\_area.
Explanation: This is a 2D shape descriptor intended to capture how close the outline is to a compact rounded object.
The implementation uses a 2D perimeter/area formula and carries µm^(-1/2); it is not standard dimensionless 3D sphericity.

**Units:** µm⁻¹ᐟ² under the implemented 2D formula. **Value shape:** Scalar.

**Availability:** emitted whenever this family calculation succeeds; ``all_data`` does not gate this key.

cell_contour_bending_energy
---------------------------

**Exported column:** ``cell_contour_bending_energy``

**Meaning:** Cell contour bending energy.

Calculation: sum(curvature^2) / line\_length for the corresponding contour or midline.
Explanation: Bending energy summarizes how much the shape bends overall; larger values indicate a more strongly curved line.
The current helper sums sampled curvature squared and divides by physical line length. This is sampling-dependent and is not an arc-length integral.

**Units:** µm⁻³ under the implemented sum(curvature²)/length. **Value shape:** Scalar.

Region-property component families
----------------------------------

These scalar components are also emitted and are not gated by ``all_data``.
They come directly from scikit-image properties in pixel coordinates and do
not receive physical calibration. The raw moments and inertia tensor carry
pixel-order units; normalized and Hu moments are dimensionless.

moments
~~~~~~~

Columns: ``moments_0_0``, ``moments_0_1``, ``moments_0_2``, ``moments_0_3``, ``moments_1_0``, ``moments_1_1``, ``moments_1_2``, ``moments_1_3``, ``moments_2_0``, ``moments_2_1``, ``moments_2_2``, ``moments_2_3``, ``moments_3_0``, ``moments_3_1``, ``moments_3_2``, ``moments_3_3``.

Raw moments sum row^i × column^j over foreground pixels; units follow the coordinate powers.

moments_central
~~~~~~~~~~~~~~~

Columns: ``moments_central_0_0``, ``moments_central_0_1``, ``moments_central_0_2``, ``moments_central_0_3``, ``moments_central_1_0``, ``moments_central_1_1``, ``moments_central_1_2``, ``moments_central_1_3``, ``moments_central_2_0``, ``moments_central_2_1``, ``moments_central_2_2``, ``moments_central_2_3``, ``moments_central_3_0``, ``moments_central_3_1``, ``moments_central_3_2``, ``moments_central_3_3``.

Central moments use coordinates relative to the mask centroid.

moments_normalized
~~~~~~~~~~~~~~~~~~

Columns: ``moments_normalized_0_2``, ``moments_normalized_0_3``, ``moments_normalized_1_1``, ``moments_normalized_1_2``, ``moments_normalized_1_3``, ``moments_normalized_2_0``, ``moments_normalized_2_1``, ``moments_normalized_2_2``, ``moments_normalized_2_3``, ``moments_normalized_3_0``, ``moments_normalized_3_1``, ``moments_normalized_3_2``, ``moments_normalized_3_3``.

Normalized central moments from regionprops; three low-order components are skipped by the utility.

moments_hu
~~~~~~~~~~

Columns: ``moments_hu_0``, ``moments_hu_1``, ``moments_hu_2``, ``moments_hu_3``, ``moments_hu_4``, ``moments_hu_5``, ``moments_hu_6``.

Seven Hu moment invariants from the binary region.

inertia_tensor
~~~~~~~~~~~~~~

Columns: ``inertia_tensor_0_0``, ``inertia_tensor_0_1``, ``inertia_tensor_1_0``, ``inertia_tensor_1_1``.

Four 2D inertia tensor components in pixel².

inertia_tensor_eigvals
~~~~~~~~~~~~~~~~~~~~~~

Columns: ``inertia_tensor_eigvals_0``, ``inertia_tensor_eigvals_1``.

Two inertia tensor eigenvalues in pixel².

Each component is scalar. Degenerate masks or undefined normalized components can produce nonfinite values. See :py:func:`bactoscoop.utilities.get_additional_regionprops_features` for generation and :doc:`../workflow/features` for row-level failure handling.
