Parameter reference
===================

Signature defaults are listed separately from settings chosen in the tutorials.
The tables below are generated from the current source. Follow each method link
for prerequisites, returned values, side effects, and source evidence.

ImageCollection
---------------

:py:class:`bactoscoop.imagecollection.ImageCollection`

.. code-block:: python

   ImageCollection(image_folder_path=None, px=0.065, error_policy='continue', log_cell_errors=False)

* ``image_folder_path`` — default ``None``. Dataset folder containing TIFFs and the masks subfolder; None delays path configuration.
* ``px`` — default ``0.065``. Micrometres per pixel. Geometry arrays remain in pixel coordinates.
* ``error_policy`` — default ``'continue'``. "continue" records independent item/cell failures; "raise" raises the recorded error. Setup failures can still stop work.
* ``log_cell_errors`` — default ``False``. Print each recorded cell error when true; recording is independent of this flag.

batch_process_mesh
------------------

:py:meth:`bactoscoop.imagecollection.ImageCollection.batch_process_mesh`

.. code-block:: python

   batch_process_mesh(pkl_name=None, object_list=None, save_data=True, phase_channel='', join_thresh=4, split_thresh=0.35, CD_width=False, smoothing=0.1, neighbor_filter_max_neighbors=None, neighbor_filter_connectivity=1, max_daughter_cell_mesh_rows=800)

* ``pkl_name`` — default ``None``. Mesh input filename or pickle output name. For feature output, .pkl means exact filename; a suffixless name is a legacy tag.
* ``object_list`` — default ``None``. Explicit image-object sequence to process; None selects collection targets.
* ``save_data`` — default ``True``. Write the combined mesh table when true.
* ``phase_channel`` — default ``''``. TIFF suffix identifying the phase images, such as "C1". An empty suffix is the signature default.
* ``join_thresh`` — default ``4``. Maximum pole-to-pole joining distance in pixels.
* ``split_thresh`` — default ``0.35``. Relative constriction threshold used by the splitting pipeline.
* ``CD_width`` — default ``False``. Use the width-based constriction path when true; otherwise use the pipeline phase-signal path.
* ``smoothing`` — default ``0.1``. Smoothing passed to the contour/mesh fitting path.
* ``neighbor_filter_max_neighbors`` — default ``None``. Maximum number of touching distinct labels allowed before meshing; None disables the prefilter.
* ``neighbor_filter_connectivity`` — default ``1``. 1 or 4 for edge contact; 2 or 8 for edge and diagonal contact.
* ``max_daughter_cell_mesh_rows`` — default ``800``. Maximum rebuilt mesh rows per daughter during cell splitting (default 800; integer >= 4). Rejects oversized predicted counts before reconstruction; both final daughters must have 4..limit rows. Does not limit unsplit parents and is separate from feature extraction max_mesh_size.

batch_calculate_features
------------------------

:py:meth:`bactoscoop.imagecollection.ImageCollection.batch_calculate_features`

.. code-block:: python

   batch_calculate_features(channel_method_pairs, all_data=True, reset=True, use_shifted_contours=False, shift_signal=False, max_mesh_size=600, retain_contour_on_object_mesh_failure_channels=None)

* ``channel_method_pairs`` — required. Pairs of (channel list, feature method), for example [([None], "morphological"), (["C2"], "profiling")].
* ``all_data`` — default ``True``. Feature-method-specific option; objects includes detailed per-object arrays when true.
* ``reset`` — default ``True``. Clear stored feature dataframes when true; false retains other pairs while replacing each recalculated pair.
* ``use_shifted_contours`` — default ``False``. Select stored shifted contour, midline, and mesh geometry; the correction must already exist.
* ``shift_signal`` — default ``False``. Enable the method-specific optional signal cropping/shift path; this is not a universal object-coordinate shift.
* ``max_mesh_size`` — default ``600``. Maximum accepted mesh row count; cells above this limit are removed from the image cell population.
* ``retain_contour_on_object_mesh_failure_channels`` — default ``None``. Channels whose object rows keep contour measurements and NaN mesh aggregates when object geometry fails.
