Svm features¶

Prerequisites: Valid cell geometry and inverse-phase signal; these quantities are used by the curation classifier.

A failed cell calculation omits that family row and records the failure. Missing values in a merged table are not automatically zero. Numerical NaN can also arise within a returned measurement. The object retention option explicitly sets invalid mesh-dependent aggregates to NaN.

contour¶

Exported column: <channel>_contour

Meaning: Stored cell contour coordinates.

Calculation: Store the cell contour coordinates directly in the table. Explanation: This is mainly kept for tracking, visualization, and linking feature rows back to the original segmented cell.

Units: pixels. Value shape: N × 2 geometry array in pixel coordinates.

Availability: emitted whenever this family calculation succeeds; all_data does not gate this key.

Normalization: No additional export-level normalization; the calculation below determines family-specific preprocessing.

Current assignment expression (a tuple expression can produce several named outputs):

cell.contour

Source assignment, line 394; bactoscoop.features.Features.svm().

cell_length¶

Exported column: <channel>_cell_length

Meaning: Cell length along the mesh midline.

Calculation: Sum the step lengths between successive mesh midpoints along the cell axis. Explanation: This is the measured pole-to-pole length of the cell, following the fitted midline rather than a simple straight line.

Units: µm. Value shape: Scalar.

Availability: emitted whenever this family calculation succeeds; all_data does not gate this key.

Normalization: No additional export-level normalization; the calculation below determines family-specific preprocessing.

Current assignment expression (a tuple expression can produce several named outputs):

u.get_length(step_length)

Calculation helpers: bactoscoop.utilities.get_length().

Source assignment, line 397; bactoscoop.features.Features.svm().

cell_width¶

Exported column: <channel>_cell_width

Meaning: Cell body width.

Calculation: Compute the width of every mesh segment as the distance between (x1, y1) and (x2, y2), sort those widths, and take the mean of the widest one-third. Explanation: This gives a robust estimate of the cell body width while reducing the influence of the narrow poles.

Units: µm. Value shape: Scalar.

Availability: emitted whenever this family calculation succeeds; all_data does not gate this key.

Normalization: No additional export-level normalization; the calculation below determines family-specific preprocessing.

Current assignment expression (a tuple expression can produce several named outputs):

u.get_avg_width(cell.x1, cell.y1, cell.x2, cell.y2, px)

Calculation helpers: bactoscoop.utilities.get_avg_width().

Source assignment, line 398; bactoscoop.features.Features.svm().

cell_volume¶

Exported column: <channel>_cell_volume

Meaning: Cell estimated volume.

Calculation: Treat each mesh segment as a cylinder with radius width/2, integrate pi*(width/2)^2 along the cell length using the trapezoidal rule, and sum the segments. Explanation: This estimates the 3D volume of the bacterium from its 2D mesh.

Units: µm³. Value shape: Scalar.

Availability: emitted whenever this family calculation succeeds; all_data does not gate this key.

Normalization: No additional export-level normalization; the calculation below determines family-specific preprocessing.

Current assignment expression (a tuple expression can produce several named outputs):

u.get_volume(cell.x1, cell.y1, cell.x2, cell.y2, step_length, px)

Calculation helpers: bactoscoop.utilities.get_volume().

Source assignment, line 402; bactoscoop.features.Features.svm().

cell_surface_area¶

Exported column: <channel>_cell_surface_area

Meaning: Cell estimated surface area.

Calculation: For each mesh segment compute 2*pi*(width/2)*step_length and sum the segment values. Explanation: This estimates the outer surface area of the cell envelope along the reconstructed cell shape.

Units: µm². Value shape: Scalar.

Availability: emitted whenever this family calculation succeeds; all_data does not gate this key.

max_curvature¶

Exported column: <channel>_max_curvature

Meaning: Maximum cell contour curvature.

Calculation: Compute curvature as |x’y’’ - y’x’’| / (x’^2 + y’^2)^(3/2) along the relevant contour or midline, then report the requested summary statistic. Explanation: Curvature describes how strongly the line bends; higher values indicate sharper turns or tighter bends.

Units: µm⁻¹. Value shape: Scalar.

Availability: emitted whenever this family calculation succeeds; all_data does not gate this key.

Normalization: No additional export-level normalization; the calculation below determines family-specific preprocessing.

Current assignment expression (a tuple expression can produce several named outputs):

u.get_curvature_characteristics(cell.contour, px)

Calculation helpers: bactoscoop.utilities.get_curvature_characteristics().

cell_circularity¶

Exported column: <channel>_cell_circularity

Meaning: Cell circularity.

Calculation: (4*pi*cell_area) / (cell_perimeter^2). Explanation: Values closer to 1 indicate a more circle-like outline, while lower values indicate a more elongated or irregular shape.

Units: Dimensionless (GLCM descriptors use quantized intensity bins). Value shape: Scalar.

Availability: emitted whenever this family calculation succeeds; all_data does not gate this key.

cell_sphericity¶

Exported column: <channel>_cell_sphericity

Meaning: Cell sphericity descriptor.

Calculation: (1.5*pi*(cell_perimeter/(2*pi))^1.5) / cell_area. Explanation: This is a 2D shape descriptor intended to capture how close the outline is to a compact rounded object. The implementation uses a 2D perimeter/area formula and carries µm^(-1/2); it is not standard dimensionless 3D sphericity.

Units: µm⁻¹ᐟ² under the implemented 2D formula. Value shape: Scalar.

Availability: emitted whenever this family calculation succeeds; all_data does not gate this key.

Normalization: No additional export-level normalization; the calculation below determines family-specific preprocessing.

Current assignment expression (a tuple expression can produce several named outputs):

u.get_cell_perimeter_measurements(cell.contour, cell.svm_features['cell_area'], px)
